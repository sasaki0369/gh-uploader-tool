GitHub 自動アップローダー

ファイルを選んでリポジトリ情報を入力し、ボタン一つでコミット＆プッシュします。すべてこのページ内（ブラウザ）で完結し、外部サーバーは経由しません。

保存されているトークンはありません。
GitHub → Settings → Developer settings → Fine-grained tokens で発行（対象リポジトリの Contents: Read and write 権限）。「保存」を押すとこのブラウザにのみ保存され、次回以降は自動で読み込まれます。アップロード時は常に保存済みのトークンが使われるため、別のトークンに切り替える場合は入力後に必ず「保存」を押してください。保存したトークンを削除
1ファイルのみ選択時は、このパスがそのままファイル名として使われます。複数ファイル選択時は、ここは配置先フォルダ（空欄ならリポジトリ直下）として扱われ、各ファイルは元のファイル名のまま配置されます。
クリックまたはドラッグ＆ドロップでファイルを選択（複数可）
このページはGitHub Pagesで公開されていますが、ページ自体にトークンは埋め込まれていません。入力したトークンはこの端末のブラウザ内（localStorage）にのみ保存され、GitHub API以外には送信されません。共有端末で使う場合は、使い終わったら上の「保存したトークンを削除」を押すか、GitHub側でトークンを失効させることをおすすめします。
